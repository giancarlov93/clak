# Sounds

| File | Plays when | Format |
|---|---|---|
| `connect.wav` | An agent connects, together with the impact strokes beside the antenna on the tray icon. | Mono, 48 kHz, 16-bit PCM, 79 ms. The attack is on the first sample. Peak -3.7 dBFS, active RMS -20 dBFS. |
| `consent.wav` | A consent window opens, if Sound for consent windows is on in Settings. | Mono, 48 kHz, 16-bit PCM, 133 ms. The attack is on the first sample. Peak -6.2 dBFS, active RMS -20 dBFS. |
